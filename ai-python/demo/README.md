# AI 代码分析演示页面

## 简介
这是一个简单的交互式演示页面，用于展示 AI 教学辅助平台的代码分析和调试功能以及题目推荐功能。

## 功能
1. **代码编辑器**：支持 C/C++ 代码输入，带行号显示
2. **题目描述**：输入题目要求和说明
3. **测试点**：支持 JSON 格式的测试点输入
4. **学生薄弱点信息**：支持 JSON 格式
5. **YOJ题库信息（可选）**：正式版应从数据库读取
6. **任务类型**：三个功能可选择
7. **分析结果展示**：实时显示 AI 分析结果

## 使用方法
1. 确保 AI Python 服务正在运行：`uvicorn main:app --host 0.0.0.0 --port 8000`
2. 在浏览器中打开 `demo/index.html`
3. 输入或修改示例代码和题目描述
4. 选择任务类型
5. 点击"提交分析"按钮
6. 查看右侧的分析结果

## API 接口
- **评价接口**：POST `http://localhost:8000/evaluate`
- **调试接口**：POST `http://localhost:8000/debug`
- **推荐接口**：POST `http://localhost:8000/recommend`

## 注意事项
1. 确保 AI 服务已启动且可访问
2. 测试点使用 JSON 格式，字段包括 `input` 和 `status`
3. 页面使用纯前端技术，无需后端编译
4. 这只是演示版本，样式和功能较为简单
